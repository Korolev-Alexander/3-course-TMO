# Лабораторная работа №4
## Линейные модели, SVM и деревья решений

### Задание
1. Выбрать набор данных (использован датасет Global Minimum Wage)
2. Провести удаление или заполнение пропусков и кодирование категориальных признаков
3. Разделить выборку на обучающую и тестовую (train_test_split)
4. Обучить следующие модели:
   - Линейную регрессию
   - SVM (SVR)
   - Дерево решений (DecisionTreeRegressor)
5. Оценить качество моделей с помощью метрик RMSE, MAE, R2
6. Сравнить качество полученных моделей
7. Построить график важности признаков в дереве решений
8. Визуализировать дерево решений

### Используемые библиотеки
- pandas, numpy
- matplotlib
- scikit-learn (LinearRegression, SVR, DecisionTreeRegressor, train_test_split, StandardScaler, SimpleImputer)
