# Лабораторная работа №5
## Ансамбли моделей машинного обучения. Часть 1.

### Задание
1. Выбрать набор данных (Global Minimum Wage)
2. Заполнить пропуски, закодировать категориальные признаки
3. Разделить выборку на обучающую и тестовую
4. Обучить ансамблевые модели:
   - Bagging
   - Random Forest
   - Extra Trees (сверхслучайные деревья)
   - AdaBoost
   - Gradient Boosting
5. Оценить качество моделей (R2, RMSE, MAE)
6. Сравнить результаты
