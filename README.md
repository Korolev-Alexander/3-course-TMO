# Лабораторная работа №2: Предобработка данных

## Тема
Обработка пропусков, кодирование категориальных признаков, масштабирование данных

## Датасет
Global Minimum Wage Dataset (170+ стран)

## Состав работы
1. Анализ пропусков и их обработка (удаление, заполнение, создание новых признаков)
2. Кодирование категориальных признаков (Label Encoding, One-Hot Encoding)
3. Масштабирование числовых признаков (StandardScaler, MinMaxScaler)

## Результаты
- Обработаны пропуски в 7 колонках
- Созданы новые признаки: has_minimum_wage, признаки из Notes
- Выполнено кодирование валют и периодов выплат
- Проведено сравнение методов масштабирования
