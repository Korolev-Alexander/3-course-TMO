# Лабораторная работа №1: Разведочный анализ данных

## Тема
Визуализация и анализ датасета Wine из библиотеки scikit-learn

## Цель работы
Изучение различных методов визуализации данных на этапе разведочного анализа.

## Задание
1. Выбрать набор данных (использован датасет Wine из scikit-learn)
2. Создать ноутбук с разделами:
   - Текстовое описание набора данных
   - Основные характеристики датасета
   - Визуальное исследование датасета
   - Информация о корреляции признаков
3. Сформировать отчет и разместить в репозитории

## Структура проекта
- `lab1_wine_analysis.ipynb` - Jupyter ноутбук с анализом данных
- `README.md` - описание проекта
- `requirements.txt` - зависимости проекта

## Используемые библиотеки
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Результаты работы
В ходе выполнения лабораторной работы был проведен разведочный анализ датасета Wine, включающий:
- Статистическое описание данных
- Визуализацию распределений (гистограммы, box plots)
- Анализ взаимосвязей между признаками (pairplot)
- Исследование корреляций (тепловая карта, анализ сильных корреляций)

## Выводы
- Датасет не содержит пропущенных значений
- Выявлены сильные корреляции между некоторыми признаками (flavanoids-total_phenols, color_intensity-flavanoids)
- Наиболее информативными признаками для классификации являются proline, flavanoids и color_intensity
- Для дальнейшего построения моделей рекомендуется учитывать мультиколлинеарность признаков
