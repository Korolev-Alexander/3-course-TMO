**Автор:** Королев А.С.  
**Группа:** ИУ5Ц-81Б  
**Дисциплина:** Технологии машинного обучения  
**Тип работы:** НИРС (типовое исследование)

---

##  Описание проекта

В рамках данного исследования решается задача **бинарной классификации** — прогнозирование оттока клиентов (Churn) на основе открытого датасета Telco Customer Churn.

**Цель работы:** построить модель машинного обучения, которая по историческим данным о клиенте может предсказать, покинет ли он компанию в ближайшее время.

**Датасет:** [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) (7043 записи, 21 признак)

---

##  Основные этапы работы

1. **Разведочный анализ данных (EDA)**
   - Анализ распределений и корреляций
   - Визуализация ключевых зависимостей
   - Выявление дисбаланса классов (73.5% / 26.5%)

2. **Предобработка данных**
   - Удаление неинформативных признаков (`customerID`)
   - Заполнение пропусков (медиана для `TotalCharges`)
   - Замена значений 'No internet service' → 'No'
   - Создание новых признаков (`AvgMonthlyCharges`, `IsLongTerm`, `HighMonthlyCharges`)
   - One-Hot кодирование категориальных признаков
   - Масштабирование числовых признаков

3. **Построение моделей**
   - Logistic Regression
   - Decision Tree
   - Random Forest
   - XGBoost
   - LightGBM

4. **Оценка качества**
   - Метрики: Accuracy, Precision, Recall, F1-score, ROC-AUC
   - Baseline vs Tuned (после подбора гиперпараметров GridSearchCV)

5. **Веб-приложение** (Streamlit)
   - Интерактивный интерфейс для предсказания оттока
   - Возможность изменения гиперпараметров модели в реальном времени
