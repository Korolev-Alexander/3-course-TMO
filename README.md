# Лабораторная работа №3: Метод ближайших соседей (KNN)

## Тема
Подготовка обучающей и тестовой выборки, кросс-валидация и подбор гиперпараметров на примере метода ближайших соседей (KNN) для задачи регрессии.

## Цель работы
Изучение способов подготовки выборки и подбора гиперпараметров на примере метода ближайших соседей (K-Nearest Neighbors).

## Используемый датасет
**Global Minimum Wage** — набор данных о минимальной заработной плате по странам мира (186 стран, 7 признаков).  
**Задача:** регрессия — предсказание минимальной заработной платы в USD на основе признаков страны.

## Выполненные этапы
1. **Загрузка и анализ предобработанных данных** (данные подготовлены в Лабораторной работе №2)
2. **Формирование признакового пространства** — отбор признаков без пропусков для корректной работы KNN
3. **Масштабирование признаков** — применение `StandardScaler` (критически важно для KNN)
4. **Разделение выборки** — `train_test_split` с параметрами test_size=0.2, random_state=42
5. **Обучение базовой модели** — KNN с произвольным гиперпараметром K=5
6. **Подбор гиперпараметров** — `GridSearchCV` и `RandomizedSearchCV` с кросс-валидацией (KFold, ShuffleSplit)
7. **Сравнение метрик качества** — RMSE, MAE, R²
